# 玩家最大 HP（k=3，血条适配）

> 目标：玩家最大 HP 曲线整体 ×3，同时满级血条的物理长度保持原版比例；伤害数值不变时，受伤扣掉的条长比例变成原来的 1/3。

## 原作机制

- 玩家最大 HP 不是 `NpcParam.hp`，也不是 `CharaInitParam.baseHp`。
- 它由 `CalcCorrectGraph.param` 行 `500`（`HP`）插值决定。
- 当前原版数据：
  - `stageMaxVal0 = 1`
  - `stageMaxVal1 = 11`
  - `stageMaxGrowVal0 = 320`
  - `stageMaxGrowVal1 = 1120`
- 即：
  - 开局最大 HP：`320`
  - 每获得 1 条念珠串（4 颗念珠）：成长等级 +1，最大 HP `+80`
  - 10 条念珠串后：最大 HP `1120`

血条相关字段在 `MenuParam.param` 行 `0`：

| 字段 | 原版 |
|---|---:|
| `PlayerMaxHpLimit` | 1920 |
| `PlayerMaxAddHp` | 0 |
| `PlayerQuarterHp` | 20 |
| `HealthHpNoDamage` | 300 |
| `HealthHpLightDamage` | 250 |
| `HealthHpHeavyDamage` | 100 |
| `HealthHpDying` | 1 |
| `HealthHpDead` | 0 |

## k=3 修改值

整体乘以 `k = 3`：

| 项目 | 原版 | k=3 |
|---|---:|---:|
| 开局最大 HP | 320 | 960 |
| 每条念珠串 | +80 | +240 |
| 10 条后最大 HP | 1120 | 3360 |
| `PlayerMaxHpLimit` | 1920 | 5760 |
| `PlayerQuarterHp` | 20 | 60 |
| `HealthHpNoDamage` | 300 | 900 |
| `HealthHpLightDamage` | 250 | 750 |
| `HealthHpHeavyDamage` | 100 | 300 |
| `HealthHpDying` | 1 | 3 |
| `HealthHpDead` | 0 | 0 |

写入位置：

- `CalcCorrectGraph.param` 行 500：
  - `+0x14 stageMaxGrowVal0 = 960`
  - `+0x18 stageMaxGrowVal1 = 3360`
  - `+0x1C stageMaxGrowVal2 = 3360`
  - `+0x20 stageMaxGrowVal3 = 3360`
  - `+0x24 stageMaxGrowVal4 = 3360`
- `MenuParam.param` 行 0：
  - `+0x08 PlayerMaxHpLimit = 5760`
  - `+0x1C PlayerMaxAddHp = 0`
  - `+0x9C PlayerQuarterHp = 60`
  - `+0x38 HealthHpNoDamage = 900`
  - `+0x3C HealthHpLightDamage = 750`
  - `+0x40 HealthHpHeavyDamage = 300`
  - `+0x44 HealthHpDying = 3`
  - `+0x48 HealthHpDead = 0`

## 使用

只看不改：

```powershell
powershell -ExecutionPolicy Bypass -File tools\patch_paper_params.ps1
```

应用：

```powershell
powershell -ExecutionPolicy Bypass -File tools\patch_paper_params.ps1 -Apply
```

其他倍率：

```powershell
powershell -ExecutionPolicy Bypass -File tools\patch_paper_params.ps1 -Apply -HpMultiplier 2
```

关闭血量补丁：

```powershell
powershell -ExecutionPolicy Bypass -File tools\patch_paper_params.ps1 -Apply -SkipHp
```

cfg 控制：

```ini
# 血量功能: 开
# 血量倍率: 3
```

回滚：

```powershell
powershell -ExecutionPolicy Bypass -File tools\patch_paper_params.ps1 -Revert
```

回滚会使用 `gameparam.parambnd.dcx.bak-*` 中最近一次备份，连同本次 HP 改动一起恢复。

## DLL 旧存档运行时修正

param 侧只负责 HP 曲线和血条基准；只狼老存档还会缓存具体最大 HP，因此需要 DLL 运行时修正。

DLL 使用 `src/health.rs`，按以下 `PlayerData` 字段工作：

| 偏移 | 类型 | 含义 |
|---:|---|---|
| `0x18` | u32 | 当前 HP |
| `0x1c` | u32 | 实际最大 HP |
| `0x20` | u32 | 基础/缓存最大 HP |
| `0x44` | u8 | HP 等级（1..11；11 = 10 条念珠串满级） |

cfg 控制：

```ini
# 旧存档血量修正: 开
# 血量倍率: 3
# 最大血量偏移: 0x20
# 实际最大血量偏移: 0x1c
# 当前血量偏移: 0x18
# 血量等级偏移: 0x44
```

注意：

- `血量倍率` 同时被 param 补丁脚本和 DLL 读取。
- 改 `血量倍率` 后：
  - param 侧需要重新双击 `纸人挂.bat` / `paperman.bat`，或运行一次 `tools\patch_paper_params.ps1 -Apply`；
  - DLL 侧需要重进游戏。
- 新存档/已修正存档如果 `0x20` 已是目标值，不会二次乘算。
