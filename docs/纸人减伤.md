# 纸人减伤

## 功能

玩家被敌人实际打中并损失 HP 时，消耗纸人减免本次 HP 伤害。

攻击等级按**本次原始 HP 伤害 / 玩家最大血量**划分，与当前血量波动无关：

| 等级 | 原始伤害区间 | 纸人充足时 | 减免 |
|---|---|---:|---:|
| 第一等级 | `9% <= D <= 33%` | 消耗 1 个 | 60% |
| 第二等级 | `33% < D <= 66%` | 消耗 2 个 | 60% |
| 第三等级 | `D > 66%` | 消耗 3 个 | 60% |

`D < 9%` 时不消耗纸人，也不进行替伤减免。

纸人不足时：

| 等级 | 可用纸人 | 消耗 | 减免 |
|---|---:|---:|---:|
| 第二等级 | 1 | 1 | 30% |
| 第三等级 | 2 | 2 | 30% |
| 第三等级 | 1 | 1 | 20% |
| 任意等级 | 0 | 0 | 0% |

临时纸人（血纸人）和普通纸人都计入可消耗总数。扣除顺序固定为：

1. 临时纸人，物品 ID `1001`
2. 普通纸人，物品 ID `1000`

减免量按四舍五入取整：

```text
mitigated = round(raw_damage * percent / 100)
final_damage = raw_damage - mitigated
```
## 实现位置

- `src/paper_guard.rs`：分档、扣除、纸人库存读取、伤害字段缩放。
- `src/flow.rs`：在原伤害反应函数执行前调用 `prepare_damage`，执行后调用 `finish_damage`。
- `src/core.rs`：启动时读取 cfg 并初始化纸人减伤。
- `src/game.rs`：沿用已有的玩家伤害反应函数地址 `0x140B6E6A0`。

## 运行时字段

当前测试版本为 Sekiro 1.6：

| 数据 | 位置 |
|---|---|
| 原始 HP 伤害 | `DamageInfo + 0x1E0`，i32 |
| 玩家目标指针 A | `DamageInfo + 0x198`，u64 |
| 玩家目标指针 B | `DamageInfo + 0x280`，u64 |
| 最大 HP | `PlayerData + 0x1C`，u32 |
| 当前 HP | `SprjChrDataModule + 0x130`，i32 |
| 普通纸人数量 | 背包 `item_id = 1000` 条目的 `+0x08`，u16 |
| 临时纸人数量 | 背包 `item_id = 1001` 条目的 `+0x08`，u16 |

最大 HP 在**每次受击时重新读取**，不是启动时缓存。因此换存档、升级体力、复活或其它修改最大 HP 的情况，下一次受击会自动按新的 `max_hp` 分档；不需要手动刷新。

## 配置

```ini
纸人减伤功能: 开
纸人减伤调试日志: 关
```

调试日志打开后会在 `battle_instinct.log` 输出每刀的分档、原始伤害、减伤后伤害、纸人数变化和实际 HP 掉落。

## 与心流的关系

- 普通受击仍然会清空心流层数。
- 完美弹反不掉血，因此不会消耗纸人。
- flow 记录到的是减伤后的实际 HP 掉落，心流状态机逻辑不受影响。
## 已知限制

- 固定地址和 DamageInfo 偏移对应当前 Sekiro 1.6 测试版本，换游戏版本后可能需要重新定位。
- 当前不使用游戏原生的消耗物品函数，而是直接写背包数量；HUD 会在游戏刷新背包时同步。
- 只处理实际造成 HP 损失的玩家受击；中毒、火焰、跌落等是否经过该伤害钩子取决于游戏原逻辑。
